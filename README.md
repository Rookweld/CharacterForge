# Character Forge / Quest Forge

Character Forge / Quest Forge is a local-first creative desktop application. The v1.0 FOUNDATION target is a Windows-first Tauri desktop shell with a TypeScript frontend, Rust application core, and local SQLite storage.

## Project status

The repository is at Mission 00 — IGNITION. This mission establishes the engineering workspace and documents the architecture; it does not implement character or quest generation. See [the Mission 00 report](docs/missions/MISSION_00_REPORT.md) and [project state](GAZINGA/PROJECT_STATE.md) for the verified status and environment blockers.

## Development

Tool requirements and commands will be recorded here as the baseline toolchain is established. Do not treat the current bootstrap skeleton as a shippable application.

The v1.0 product boundaries and technical baseline are defined by the GAZINGA canonical documents and the v1.0 FOUNDATION World Bible. Later missions add product behavior; this repository setup does not implement it.
